# Award themes — honest product alignment

These are design goals based on the three award descriptions the team supplied. The [NASA Space Apps awards page](https://www.spaceappschallenge.org/2025/awards/) published the same descriptions in 2025; confirm the 2026 rules before submission. None of these features guarantees a nomination or award.

| Theme | Working product evidence | Important gap |
|---|---|---|
| Best Use of Data — make space data accessible or use it for a distinctive purpose | A map point opens source-labeled NASA POWER daily history. The coverage ring, valid-day counts, period, variables, units and limitations let a visitor audit the record. The conversation panel translates one selected question into a bounded observation rather than a guessed crop answer. | IMERG complete-day retrieval remains unreliable; worldwide soil and crop suitability are not integrated. A memorable demo must show how the data changes a real decision discussion, not merely a satellite map. |
| Most Inspirational — capture hearts | The interface starts with a question a person cares about and admits what it cannot know. It does not fabricate a farmer, interview, yield gain or hardship. | A real, consented farmer or published first-person case and a focused three-minute story would be stronger than UI copy. This has not been obtained or validated. |
| Global Connection — connect people through technology | Six clearly labeled public example points across continents can be explored and encoded in a privacy-limited link. On a public HTTPS deployment, another visitor can open the same location, period and question and request the same NASA source. | The current localhost link works only on this computer. A public deployment, cross-region user testing and consented feedback are needed before claiming actual global connection. A link alone is not demonstrated collaboration or worldwide agronomic relevance. |

## Demo path

1. Choose a public example in one region; load NASA POWER; inspect valid-day coverage and the historical question.
2. Copy the public example link, open it in a second browser, and show that the same place, years and question return without any private field information or automatic data request.
3. Switch to another continent to show the data layer's reach, then state plainly that crop recommendations need local evidence and agronomist review.
