# Farm overview image provenance

The images under `assets/` were made with the built-in image-generation tool for visual design. They are decorative illustrations, not observations of the selected farm, NASA imagery, or evidence of crop health. NASA values in the interface come from NASA POWER responses, not these images.

## `assets/farm-overview.jpg`

> Use case: photorealistic-natural. Asset type: wide background photograph for a farm decision-support dashboard. Use the user's attached screenshot only as a mood and palette reference, not as an edit target or layout template. Create a realistic aerial oblique view of lush crop fields with subtle rows, field boundaries, and a distant tree line at golden-hour overcast light. Deep forest green and olive tones, enough darker low-detail area behind white dashboard cards and text. High-end editorial agricultural photography, natural color, real texture, no heavy blur. No people, tractors, icons, diagrams, charts, labels, numbers, text, logos, or watermark. No claims about crop condition or health. Wide landscape composition.
